# finder-pane — 返答に出たパスを Finder で開く

Claude Code の MOD（Mac 専用）。Claude の返答が終わるたびに、本文からローカルのファイル・フォルダのパスらしい語を拾い、実在するものだけを会話の横の「ファイル」ペインに並べます。行をクリックするか、ペインに焦点を移して（`ctrl+x tab`）数字キーを押すと、ファイルは Finder で選択状態に（`open -R`）、フォルダはそのフォルダが開きます。`.app` などのバンドルとシンボリックリンクは、起動させないよう `open -R` で見せるだけにします。

## 入れ方

ターミナルのセッションのプロンプトで:

```
/plugin install finder-pane --marketplace i-noma-ru/finder-pane
```

marketplace を足すかの問いに `y`、続けて範囲を選びます（user を選ぶと毎回のセッションで有効）。

## 拾うもの・拾わないもの

- 拾う: スラッシュを含む相対パス（`docs/dev_log.md`・作業フォルダ基準）、絶対パス（`/Users/…`）、`~/…`。日本語の句読点・括弧・バッククォートを語の切れ目として扱うので、日本語の文中のパスも拾う
- 拾わない: URL、`*` を含む glob、スラッシュの無いファイル名だけ（`03_見出し.png`）、ディスクに無いもの
- 1 返答につき最大 9 件。新しい返答で入れ替わる。サブエージェントの報告は読まない

## コマンド

- `/files` でペインの開閉。パスが見つかった返答のたびに、閉じていれば開く

## 条件

- macOS（`open` コマンドを使う）。Windows・Linux は未対応
- 勝手に開くにはターミナルの幅が 144 桁要る（`/files` で一度開いて、手で閉じていなければ 110 桁）。`/files` で開くときは幅を問わない
- 他の MOD のペインがあると、勝手に開いたペインはその後ろのタブに入ることがある。そのときは「ファイル N 件 — /files で表示」のトーストで知らせる

## 構成

- `hooks/register.tsx`: フック（`turn.complete`・ペインの `ui.render`・`/files`）
- `hooks/logic.ts`: パスの抽出と解決の純粋関数
- `types/index.d.ts`: `$.state` の契約
- `tests/finder-pane.test.tsx`: `claude plugin test` で回すテスト
